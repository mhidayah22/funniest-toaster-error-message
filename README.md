The funniest error message a kitchen toaster would show its owner — one line,
90 characters, deadpan as a fault code:

> ERROR E-07: Toast level set to 'regret'. Ejecting charcoal. Please apologise to the bread.

## Run it

```sh
python3 main.py
```

It checks the line is a single line of at most 120 characters, then writes it to
`entry.txt` inside `MAKEFUN_OUTPUT_DIR`.
